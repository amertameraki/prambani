# Prambani Ami — Introduction

A responsive, static HTML professional profile. No build tools or external dependencies are required.

## Files
- `index.html`: profile and career content
- `style.css`: responsive layout and print styles
- `Prambani-Ami-Resume.pdf`: downloadable resume

## GitHub Pages
Enable Pages from Settings → Pages → Deploy from a branch → main → /(root).

Review the default GitHub Pages URL before enabling the custom domain.

## Custom domain
Intended address: introduction.prambani.com
Set the custom domain in GitHub Pages, then add a CNAME record in the authoritative DNS provider:
- Name: introduction
- Target: amertameraki.github.io

Do not change the main website’s DNS records. Enable HTTPS after GitHub issues the certificate.
